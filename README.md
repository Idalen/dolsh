# Dolsh

A temptative terminal-based music player made by and for Jellyfin users.

## Foreseeable Roadmap
- Create a master model in the UI to orchestrate screen definitions, switches, context propagation, etc...
- Create the library browser with albums, artists and metadata. Render the album cover.
- Transportation interface should have a builder pattern, instead of a sole function.
- Login is done by an option. It should be more explicit.
