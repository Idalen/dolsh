# Dolsh

A temptative terminal-based music player made by and for Jellyfin users.

## Foreseeable Roadmap
- Create the library browser with albums, artists and metadata. Render the album cover.
- Transportation interface should have a builder pattern, instead of a sole function.
- Login is done by an option. It should be more explicit.
- Layout data within screens should be remodelled. (think about it)
- A screen could have multiple screens inside of it. Like a n-tree. So the player could have multiple screens at the same time
- Local caching of music metadata and stuff like this.
- Fuzzy Finder to look up album, artist, year,
